拾光・家庭密碼管家 V1.9.2｜專案清理版

本版以 V1.8.7 為基礎，僅整理部署檔案、版本資訊和使用說明；不調整加密演算法、帳號資料結構與業務邏輯。

【檔案用途】
index.html：頁面及表單
style.css：響應式樣式
app.js：帳號操作、分類、加密與備份邏輯
sw.js：PWA 離線快取與更新
manifest.webmanifest：PWA 安裝資訊
icon.svg、icons/：品牌及裝置圖示
README.txt：本說明，不影響網站執行

【部署到 GitHub Pages】
1. 先從舊版系統「設定 → 加密備份」匯出加密 JSON，並實際確認已安全保存。
2. 解壓縮本 ZIP，將網站檔案放進 GitHub 專案根目錄（與 index.html 同層）。
3. 刪除專案內以前版本的 ZIP、版本說明和不再引用的舊檔；不要清除瀏覽器網站資料。
4. GitHub Desktop 提交 (Commit) 後推送 (Push)。
5. 開啟 HTTPS 網站並檢查版本顯示 V1.9.2、帳號數、分類、新增/編輯、備份及還原流程。

【資料安全】
本版程式碼壓縮檔不包含任何個人帳號、密碼或加密備份內容。
密碼資料位於使用者瀏覽器本機儲存空間，更新網站檔案並不會自動遷移資料。
請不要在尚未驗證備份可還原前清除網站儲存資料；不同裝置不會自動同步。
