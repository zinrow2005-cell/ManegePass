拾光・家庭密碼管家 V1.9.4｜檢查與家人編輯修正版

本版直接以您上傳的 V1.9.2 為基礎，修正家人編輯、搜尋與列表顯示。保留加密演算法、帳號資料結構與原有資料儲存鍵值。

【檔案用途】
index.html：頁面及表單
style.css：響應式樣式
app.js：帳號操作、分類、加密與備份邏輯
sw.js：PWA 離線快取與更新
manifest.webmanifest：PWA 安裝資訊
icon.svg、icons/：品牌及裝置圖示
README.txt：本說明，不影響網站執行

【部署到 GitHub Pages】
1. 先從舊版系統「設定 → 加密備份」匯出加密 JSON，並實際確認已安全保存。
2. 解壓縮本 ZIP，將網站檔案放進 GitHub 專案根目錄（與 index.html 同層）。
3. 刪除專案內以前版本的 ZIP、版本說明和不再引用的舊檔；不要清除瀏覽器網站資料。
4. GitHub Desktop 提交 (Commit) 後推送 (Push)。
5. 開啟 HTTPS 網站並檢查版本顯示 V1.9.4、帳號數、分類、新增/編輯、備份及還原流程。

【資料安全】
本版程式碼壓縮檔不包含任何個人帳號、密碼或加密備份內容。
密碼資料位於使用者瀏覽器本機儲存空間，更新網站檔案並不會自動遷移資料。
請不要在尚未驗證備份可還原前清除網站儲存資料；不同裝置不會自動同步。

V1.9.4 修正摘要
- 家庭成員新增「編輯」：可更換名稱與 Emoji，保留原成員 ID 與帳號關聯。
- 搜尋可依所屬家人名稱篩選，快速搜尋提示顯示所屬家人和分類。
- 帳號列表固定顯示所屬家人標籤。
- 清理備份檔命名函式中的不可執行重複程式碼。
- 不改動加密格式與儲存鍵值；升級前仍應先備份。
- Google Drive 維持免 OAuth 的手動加密檔備份。


【V1.9.4 快速搜尋修正】
- 原本快速搜尋最多只顯示 6 筆帳號、4 個分類；現已移除此限制。
- 搜尋顯示符合帳號總數，預設顯示前 80 筆；更多資料可按「顯示更多」，直到全部列出。
- 搜尋結果固定標示所屬家人；搜尋時不受先前選中的分類限制，但仍尊重明確指定的家人篩選。
- 搜尋結果清單可捲動，包含分類與家人名稱匹配；保留原始帳密及備份資料格式。

【人工驗收】
建立 12 筆名稱相同但家人不同的測試帳號，確認搜尋結果顯示 12 筆並能逐筆開啟。再用 90 筆模擬資料確認「顯示更多」可顯示所有結果。
