拾光・家庭密碼管家 V2.0.7｜加密還原失敗回復修正版

本版從 V2.0.6 修改，保持既有加密格式、資料庫名稱、使用者識別與手動備份方式。

修正：空白保險箱還原後若讀回驗證失敗，透過 IndexedDB 原子比對並刪除未驗證寫入；若另有分頁更新，拒絕刪除以免毀損新資料。原本已有資料的保險箱仍保留既有加密安全副本及復原邏輯。

內建自我測試新增空白保險箱還原失敗的回復測試；自測暫存鍵改為每次唯一，避免兩個分頁執行自測互相干擾。

更新方法：先從舊版匯出加密 JSON 備份，確認檔案存在，再將 ZIP 解壓縮後以 GitHub Desktop 上傳整個專案。切勿清除瀏覽器網站資料；不要把重要密碼唯一保存在尚未全面驗收的系統。

已確認：語法、靜態結構和模擬交易邏輯。尚未完成：iPhone Safari 實機、真實 Chrome 跨分頁／跨裝置備份還原端到端測試（本執行環境阻擋 localhost 及 file 網址）。
