拾光・家庭密碼管家 V1.6.0 — 個人獨立保險箱版
============================================
1. 將 ZIP 內六個網站檔案放到 GitHub Pages 專案根目錄。開啟 HTTPS 網址使用。
2. 首頁先選擇本機使用者，或點「新增獨立使用者」。每位使用者設定自己的主密碼。
3. 每位使用者都有自己獨立的 AES-GCM 加密資料庫。切換使用者會清空記憶體內解鎖資料，需另一位的主密碼才能解鎖另一份資料。
4. 您可以在自己的資料庫裡透過「家庭成員」分類紀錄您知道的家人帳號。這不會自動共享給家人。
5. Google Cloud 預先啟用 Drive API，建立 OAuth 網頁用戶端 ID，授權 GitHub Pages 的 https://帳號.github.io 來源；授權同意畫面要設定測試使用者或符合公開發布條件。
6. 每人進入自己的保險箱→設定→連接 Google 帳號。OAuth 會要求 Google Drive appDataFolder 與 email 身分授權。第一次需確認綁定個人 Google 信箱；系統拒絕用其他 Google 信箱讀寫該使用者備份。
7. 手動按「上傳加密備份」。使用的雲端空間是每個 Google 帳號自己 Drive 裡的隱藏 App 資料夾。該目錄無法透過一般 Drive UI 直接看到；每個 Google 帳號需要單獨授權。
8. 換手機：先選「新增獨立使用者」並取相同或不同顯示名稱，按「從 Google 雲端還原」，在設定內填入同一個 OAuth ID，連線原本的 Google 帳號，下載並輸入備份主密碼。雲端備份不依賴本機顯示名稱。
9. 舊版 V1.0 本機資料在首次打開 V1.1 時自動以原加密檔複製到「原本的家庭保險箱」。舊 localStorage 備份保留不刪，方便回退。其主密碼仍是舊版主密碼。
10. 本機設定檔名稱及綁定 Google 信箱儲存在同一個瀏覽器的未加密 localStorage（不含帳號密碼）。本機與雲端加密備份中會保存網站帳密、歷史等敏感資料。
11. 同一部手機／瀏覽器中的資料不會交叉顯示，但不等於裝置作業系統帳號隔離。請使用個人手機、螢幕鎖與不同主密碼，避免不信任的人取得裝置／瀏覽器控制權。
12. 本版是手動備份與還原，沒有跨裝置自動同步或合併。每次上傳會建立新的獨立版本，不會覆蓋以前的備份；可查閱最多最近30份並選擇還原。不同裝置仍不會自動合併，請核對裝置和修改時間。
13. 主密碼遺失無法解密。Google OAuth Client ID 是公開值，不可將 Client Secret 放進 GitHub Pages。
14. 有些帳號不需定期強制更換；若疑似外洩、重複使用或遭第三方存取應立即改密碼。
15. 未經獨立安全稽核；不建議正式託管高價值金融密碼或恢復碼。先用測試帳號驗證匯入、匯出、更新與雲端還原。

V1.2 新增：Google Drive 上傳採不覆蓋歷史的獨立快照、可列出備份版本並選擇還原；還原前二次確認，並盡可能在本機保留一份加密還原前快照以供緊急復原。
限制：Google appDataFolder 不可直接用一般 Drive 介面查找；舊快照不會自動清除，儲存用量會累積。多裝置備份不代表同步或衝突合併。


V1.3 更新：
- 雲端狀態顯示最近一次在本裝置成功上傳的時間（本機紀錄，非 Google 伺服器保證的全裝置狀態）。
- 勾選自動備份，儲存後約 3.5 秒嘗試上傳加密快照。只有頁面保持開啟、已解鎖、已連線 Google 且授權未過期時執行；不會背景定時同步。
- 雲端出現本裝置上次認可時間之後的新版本，會停止自動上傳並提醒先核對。手動上傳可以自行確認繼續，但不會合併資料。
- 因為各裝置只知道自己確認過的雲端快照，無法百分之百判定內容衝突，且未設可靠的跨裝置鎖定；同時開啟多台裝置修改仍有分歧風險。
- 建議先用測試帳號驗證兩台裝置的備份與還原，不建議未經審計使用於高價值密碼。

V1.6 更新：
- 加入換機還原步驟面板與手動重試備份操作。
- 列出與讀取 Google Drive 備份時，對暫時性網路或 429/5xx 錯誤做有限重試；上傳 POST 不自動重試，以免重複建立版本。
- 自動上傳以最新雲端檔案 ID 與已核對版本 ID 比較，不依賴手機時鐘或 Google 檔案時間。首次使用未知版本時保守暫停自動備份。
- 加入上傳前後本機加密資料快照一致性檢查，避免資料在上傳期間變更卻錯誤顯示已全部備份。
- 還原後預設暫停自動備份，需核對後再開啟。
- 尚未實機驗證 Google OAuth 與跨裝置流程；勿直接投入高價值密碼。


V1.6 更新：調整手機版卡片、欄位、分類頁、導覽列與整體視覺；修正 V1.5 圖示容器結構、相容舊版 Emoji 類別圖示；PWA 快取更新至 V1.6。
注意：更新前先備份原保險箱。升級不會更改加密資料鍵值或格式。瀏覽器的網站資料不可清除。


V1.7.8 Google Drive 測試：
1. 在 GitHub Pages HTTPS 網站中開啟自己的保險箱，設定 Google Cloud OAuth 用戶端 ID。
2. 用自己的 Google 帳號連線後，按「檢查 Google 雲端備份能否讀回」。
3. 使用虛構帳號建立測試資料，再手動上傳加密備份；上傳成功須完成雲端讀回驗證。
4. 用另一部裝置／Chrome 新使用者設定檔測試還原、核對帳號與密碼歷史。
5. 由另一位家人使用不同 Google 帳號重做測試，確認彼此資料不能互讀。

注意：Google appDataFolder 是隱藏的應用程式資料空間，Google Drive 網頁無法直接瀏覽。
最新備份的加密格式、讀回比對不代表跨裝置還原或安全稽核已通過。
雲端版本檢查是盡力避免衝突，不是保證跨裝置交易鎖，請避免同時編輯。
